# Agent Note：用 Leio 品牌图标替换旧鲸鱼标记

状态：已实现

English | [中文](2026-08-15-leio-brand-marks.md)

## 问题

折叠侧栏和无会话首页仍然显示 vendored DeepSeek 鲸鱼标记，而应用其他位置已经使用 Leio 品牌图标。

## 决策

两个位置统一使用已批准的 `/leio-icon.png` 资源，并通过 CSS 裁剪为圆形标记，匹配现有布局列尺寸：折叠侧栏使用 24×24 像素，首页标题使用 34×34 像素。

## 证据

侧栏和首页组件测试都断言 Leio 图标资源路径。聚焦 UI 测试集已通过，Web 构建后 `apps/web/dist/leio-icon.png` 存在。

## 备选方案

- **保留鲸鱼 SVG 并重新着色**：否决，因为仍然保留旧产品标识。
- **增加第二个品牌图标资源**：否决，因为现有批准的 Leio 图像已经用于浏览器 favicon、展开侧栏和打包应用图标。
- **按图片原始矩形尺寸使用**：否决，因为两个目标布局都要求圆形标记，并且需要与现有图标列对齐。

## 结果

两个剩余的鲸鱼位置现在共用一个品牌资源，同时保留原有布局尺寸和悬停区域。后续批准的 Leio 图像发生变化时，必须同时检查浏览器构建和桌面构建。
