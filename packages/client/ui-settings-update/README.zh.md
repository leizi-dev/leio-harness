# @leio-ai/leio-client-ui-settings-update

[English](README.md) | 中文

通用设置中的桌面更新行，仅在 Electron preload bridge 存在时渲染，因此浏览器部署不会显示无法工作的控件。

该行通过受限的 preload bridge 读取更新状态，并提供手动检查清单、下载差分补丁和重启安装。它不会接收文件系统路径、启动进程或处理更新凭据；清单校验、下载完整性校验和补丁启动都由 Electron 主进程负责。

## 模型体验

无，本包只渲染应用维护 UI，不会进入模型请求。

#### KV Cache 影响

无。

## 已知限制与暂缓事项

- 当前更新通道使用一个签名 stable 清单和只含变更文件的 NSIS 差分补丁；完整 NSIS 安装包仍作为优先缩短首次安装时间的安装物。
- 没有更新器代码的现有安装需要先手动安装一次带更新器的引导版本，之后才能自更新。
